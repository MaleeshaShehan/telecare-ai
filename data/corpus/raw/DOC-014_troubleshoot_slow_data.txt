TITLE: Troubleshooting Guide: Resolving Slow Mobile Internet Speeds

Overview:
If your mobile data connection feels sluggish, apps fail to load promptly, or videos buffer repeatedly, follow this structured diagnostic guide to optimize and restore your data speeds.

Step-by-Step Resolution:

1. Check Data Allowance & Fair Usage Status:
   Dial #170# or launch the MyDialog app to confirm that your anytime high-speed data quota is not exhausted. If you have crossed your monthly Fair Usage Policy (FUP) limit, standard throttling (e.g., 512 Kbps or 5 Mbps) applies until renewal.

2. Verify Access Point Name (APN) Settings:
   Go to Settings -> Mobile Network -> Access Point Names. Ensure that the active APN is configured correctly:
   - Name: Dialog Internet
   - APN: dialogbb (for postpaid and prepaid)
   - Proxy / Port: Not set (leave blank)
   - APN Protocol: IPv4/IPv6
   Save changes and select this profile as default.

3. Toggle Preferred Network Mode:
   Open Settings -> Mobile Network -> Preferred Network Type. If set to '3G Only' or '2G/3G Auto', change it to '5G/4G/3G/2G Auto' or 'LTE/WCDMA'. If connected to a heavily congested 4G tower, temporarily locking your device to '3G Only' can sometimes bypass bottlenecked cells for basic web browsing.

4. Clear App Cache and Reset Network Settings:
   Clear cache on lagging applications. If overall device throughput remains poor, execute a network reset: Settings -> General Management / System -> Reset -> Reset Network Settings (note: this clears saved Wi-Fi passwords).
