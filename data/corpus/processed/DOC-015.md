Overview:
Short Message Service (SMS) failures prevent sending personal texts and receiving two-factor authentication (2FA) banking OTP codes. Use this guide to resolve SMS transmission errors.

Step-by-Step Resolution:

1. Verify the SMS Center (SMSC) Number:
 An incorrect SMSC number stored on the SIM card will block outgoing text dispatch.
 - For Android: Open Messages -> Settings -> More Settings -> Text Messages -> SMS Center.
 - Ensure the number is set exactly to: +9477000003
 - If field is missing, open phone dialer, type *#*#4636#*#*, select Phone Information, locate SMSC, enter "+9477000003" and press Update.
 - For iPhone: Open Phone app, dial *5005*7672*+9477000003# and press Call.

2. Check Account Balance / Credit Limit:
 For prepaid users, verify balance (*#456#) to ensure you have at least LKR 2.50 to cover standard SMS fees if not covered by a bundle. For postpaid users, check if your credit limit has been breached.

3. Clear SMS App Storage Cache:
 Navigate to Settings -> Apps -> Messages -> Storage -> Clear Cache. Restart the messaging app.

4. Verify Blocked Numbers and Premium SMS Permissions:
 Check Settings -> Apps -> Special App Access -> Premium SMS access -> Ensure 'Always Allow' is selected. Check device Spam and Blocked lists to make sure the recipient number is not inadvertently filtered.
